# 个人主页

更新首页内容：编辑 [`homepage.md`](homepage.md)。侧栏资料在 [`_config.yml`](_config.yml)，顶部导航在 [`_data/navigation.yml`](_data/navigation.yml)，页面结构和样式分别在 [`_layouts/default.html`](_layouts/default.html) 与 [`assets/css/main.css`](assets/css/main.css)。

本地预览：运行 `bundle install`，再运行 `bundle exec jekyll serve`。GitHub Pages 从仓库根目录构建网站。

本站原先基于 [Academic Pages](https://github.com/academicpages/academicpages.github.io)，其许可证保留在 `LICENSE`。
